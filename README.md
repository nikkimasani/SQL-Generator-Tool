# SQL Generator Tool

The first version (2025) of the support SQL generator: a static page of pre-written support SQL queries.

| File | What it is |
|---|---|
| `index.html` | SQL Generator Tool |
| `sqlgen_custom.html` | Custom query templates |

Open `index.html` in a browser — no build step.

**Status:** superseded by [sql-generator](https://github.com/nikkimasani/sql-generator) and then [support-toolbox](https://github.com/nikkimasani/support-toolbox).
